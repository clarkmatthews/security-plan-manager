# Organizational profile

The **Organizational profile** is where assessors score a brand. Open it from a brand in the menu (**Open assessment**) or by clicking a function card on the dashboard.

You will see the CSF 2.0 catalog: six functions, their categories, and **106 outcomes** (subcategories). You can filter by function. Incomplete outcomes can be highlighted so you know what still needs a Current and Target.

## Scoring an outcome

For each outcome you can set:

- **Current** — how mature this outcome is today.
- **Target** — how mature it should be.

The first time a Current or Target is set, history is written automatically with **Initial Configuration Set** and you are not asked for a reason. Later changes ask for an optional **comment**. You can save without a comment. Comments show up in Assessment history so others can see why the value moved.

## Outcome details

Click an outcome to open the details panel. It includes:

- The official NIST abbreviation and full text for the function, category, and outcome.
- Whether the outcome is **included in the profile**. Uncheck this if it is out of scope; it will drop out of scores.
- Current and Target tiers, plus optional **priority**.
- Room for current and target **policies, practices, roles, and references**.
- **Notes** and considerations.
- **Evidence** already linked to this outcome, and a place to add more if you can edit evidence.
- A short **history** of Current and Target changes for this outcome.

## Assessment history

**History** (from the profile or the brand menu, if your role allows) is a table of Current and Target changes: when, who, which outcome, old value, new value, and any comment. It is read-only.
