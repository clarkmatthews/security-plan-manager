# Evidence

Evidence proves or explains an outcome. It always belongs to a **specific outcome** on a brand’s organizational profile. It is not a general file dump.

## What you can store

- A **file** (for example a policy PDF or screenshot).
- A **URL** to something already hosted elsewhere.
- **Notes** typed in the locker.

You can attach evidence from the outcome details panel. Everyone with Evidence view can open the **Evidence locker** for that brand: title, linked outcome, who added it, and when.

## Who can change it

View lets people see and download. Edit lets people add or remove items. File downloads still require Evidence view.

The dashboard **Evidence** tile is simply the count of these artifacts for the brand.
